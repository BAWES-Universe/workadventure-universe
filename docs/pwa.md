# BAWES Universe — PWA Setup

## Overview

`universe.bawes.net` is served as a Progressive Web App (PWA), making
it installable on desktop (Chrome/Edge) and mobile (Android Chrome,
iOS Safari) without a separate app store submission.

## manifest.json

Location: `play/public/manifest.json`

This file is already wired in. Verify it is referenced in the `<head>`
of `play/index.html`:

```html
<link rel="manifest" href="/manifest.json" />
```

If `index.html` is generated by Vite/Svelte, add it to `play/index.html`
or the equivalent template.

Use a tool like [Maskable.app](https://maskable.app) to verify the
maskable icon safe zone.

## Head Meta Tags

Add the following to `play/index.html` `<head>` (see `pwa-meta.html` snippet):

```html
<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content="#4f98a3" />
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
<meta name="apple-mobile-web-app-title" content="Universe" />
<link rel="apple-touch-icon" href="/static/images/universe-apple-touch-icon.png" />
```

## Testing PWA Install

**Chrome/Edge (desktop):**
1. Open `https://universe.bawes.net`
2. Click the install icon in the address bar (or ⋮ → Install BAWES Universe)
3. Verify it opens in standalone window with correct icon and title

**Android Chrome:**
1. Visit `https://universe.bawes.net`
2. Chrome shows an "Add to Home Screen" banner automatically
3. Or: ⋮ menu → Add to Home Screen

**iOS Safari:**
1. Visit `https://universe.bawes.net`
2. Share button → Add to Home Screen
3. Verify icon and title are correct

## Service Worker

The existing `service-worker-prod.js` handles caching. No changes
required from this PR — the manifest is the only missing piece for
full install eligibility.

## Lighthouse Check

Run `npx lighthouse https://universe.bawes.net --only-categories=pwa`
to verify PWA installability score after deploying.
