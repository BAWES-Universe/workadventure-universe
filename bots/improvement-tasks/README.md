# AutoPilot Improvement Tasks

This directory contains improvement task files created by AutoPilot when tests fail or metrics show issues.

Each task file contains:
- Test results
- Metrics (repetition, personality compliance, etc.)
- Failed tests
- Recommendations

**You (the AI assistant) should:**
1. Monitor this directory for new task files
2. Read and analyze task files
3. Improve code/system prompts based on issues
4. Delete task files when resolved

See: bots/docs/improvement/AUTOPILOT_WORKFLOW.md for complete workflow.
